# Plugin Conformance Template

Use this template when reviewing a Cortex plugin for local install, release packaging, or release-candidate evidence. It records operator evidence; it is not an independent certificate authority and it is not sandbox containment.

Keep one completed copy with the plugin release artifacts when the plugin is distributed as a governed package.

## Review Metadata

```text
Plugin name:
Plugin version:
Plugin repository:
Plugin commit:
Cortex target version:
Reviewer:
Review date:
Decision: pass / fail / blocked / not run
```

## Package Inputs

| Item | Status | Evidence |
|------|--------|----------|
| `manifest.toml` present and targets the exact Cortex version | not run | |
| `package.toml` generated by `cortex plugin sign` when distributing `.cpx` | not run | |
| Publisher id and public key fingerprint reviewed | not run | |
| `.cpx` hash verified when installing from a release artifact | not run | |
| SBOM path present or explicitly marked unavailable | not run | |
| Risk profile path present or explicitly marked unavailable | not run | |
| Conformance result attached to release notes or local review record | not run | |

## Governance Posture

| Check | Status | Evidence |
|-------|--------|----------|
| Trust tier is appropriate: `reviewed_process` for normal third-party tools, `trusted_native` only for trusted in-process code | not run | |
| Requested file, network, process, secret, and background capabilities match the implementation | not run | |
| Tool effects are declared per tool and include targets, reversibility, confirmation posture, and dry-run posture where relevant | not run | |
| Recommended `[risk.tools.<name>]` entries exist for each exposed tool | not run | |
| Secret-capable tools are blocked or require confirmation | not run | |
| Background-capable tools avoid high-impact mutation and declare explicit policy | not run | |
| Plugin does not present prompt, config, session, journal, memory, or runtime-state mutation as a direct model-callable shortcut | not run | |

## Local Commands

Run these from the plugin directory:

```bash
cortex plugin review .
cortex plugin test .
```

Record the exact Cortex binary used:

```text
cortex --version:
cortex plugin review . output:
cortex plugin test . output:
```

## Conformance Vectors

| Vector | Expected result | Status | Evidence |
|--------|-----------------|--------|----------|
| Invalid JSON output | Tool result is rejected | not run | |
| Non-zero process exit with stderr | stderr is surfaced as the tool error | not run | |
| Command path escapes plugin directory without `allow_host_paths = true` | Plugin is rejected | not run | |
| Working directory escapes plugin directory without explicit opt-in | Plugin is rejected | not run | |
| Secret-like environment inheritance without secret capability | Plugin is rejected | not run | |
| Output exceeds configured byte limit | Tool call fails with an output-limit error | not run | |
| Timeout exceeds or hits configured limit | Tool call fails with a timeout error | not run | |
| Process tool underreports process capability | Runtime still exposes `RunProcess:plugin subprocess` | not run | |
| Unsupported sandbox enforcement claim | Manifest is rejected instead of overclaiming isolation | not run | |
| Native ABI version mismatch or missing ABI version | Plugin is rejected before unsafe loading | not run | |
| Package archive includes hidden files, backups, symlinks, or unsupported extras | Unsupported entries are filtered or rejected according to package rules | not run | |

## Boundary Notes

- Process JSON plugins are the recommended third-party extension boundary.
- Trusted native ABI plugins run inside the daemon process and must be treated as trusted code.
- Plugin governance, policy lint, risk scoring, and conformance tests improve review quality; they do not provide OS/container sandbox containment.
- The runtime rejects sandbox enforcement claims it cannot actually enforce. Do not mark unsupported isolation as passed.
- If a vector was not run, write `not run` and keep it as a limitation.
