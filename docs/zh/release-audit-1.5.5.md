# 1.5.5 发布审计

这是 `v1.5.5` 发布目标的工作事实表。它不是发布说明，也不是营销宣称。每一行都对应 `docs/zh/roadmap.md` 中的一个必做评审领域，并记录当前证据、验证面、剩余缺口和 `1.5.5` 处理状态。

状态含义：

- **已有 surface**：代码和测试已经暴露相关 contract，但发布评审仍需复核限制。
- **部分完成**：contract 的一部分已经存在且有验收证据；剩余限制必须公开保留，不能被包装成已完成的 release claim。
- **发布阻断**：缺少必需 runtime contract 或验收证据，必须完成后才能发布 `1.5.5`。

## 发布审计要求

`v1.5.5` 切版前必须满足：

1. 每个 **发布阻断** 行都必须实现，或用代码证据、测试证据、文档和限制说明重新分类。
2. 每个 **部分完成** 行都必须有验收测试证明 release claim，或在公开限制中避免过度宣称。
3. Release report 必须包含本表最终状态、严格 Docker Compose gate 结果，以及 behavior/safety/replay/soak 证据。
4. 任何 P2 宣称不得进入 README 或 release notes，除非对应审计行不再是部分完成或发布阻断。
