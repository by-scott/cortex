# 1.6.8 发布审计

这是 `v1.6.8` 发布目标的工作事实表。它不是发布说明，也不是营销宣称。每一行都对应 `docs/zh/roadmap.md` 中的一个必做评审领域，并记录当前证据、验证面、剩余缺口和 `1.6.8` 处理状态。

状态含义：

- **已有 surface**：代码和测试已经暴露相关 contract，但发布评审仍需复核限制。
- **部分完成**：contract 的一部分已经存在且有验收证据；剩余限制必须公开保留，不能被包装成已完成的 release claim。
- **发布阻断**：缺少必需 runtime contract 或验收证据，必须完成后才能发布 `1.6.8`。

## 1.6.8 Patch 证据

`v1.6.8` 保持 `1.6` harness contract，并发布一个本地 vLLM 流式兼容补丁，
用于修正 hidden-thinking turn：

- OpenAI-compatible parser 在 provider thinking 已显式关闭时，会把
  `reasoning` 和 `reasoning_content` 当作可见答案文本处理。这修正了
  Qwen3/vLLM 在 `chat_template_kwargs.enable_thinking=false` 后返回
  reasoning delta 但没有 content delta 时，答案被误当作隐藏思考丢弃的问题。
- 显示 thinking 的模式保持不变：operator 启用 thinking 输出时，provider
  reasoning 仍会被规范化为 Cortex `<think>...</think>` 输出。
- TPN 流式边界现在会增量过滤 `<think>...</think>`，包括跨 chunk 拆开的
  tag，而不是等最终响应可用后才处理，或直接压制所有流式文本。
- 聚焦测试覆盖 reasoning-only 非流式响应、reasoning-only 流式 delta、拆分
  think tag 过滤，以及 hidden-thinking turn 仍向 provider 传递 streaming
  callback。
- 使用已配置的 Qwen3 vLLM endpoint 做本地 smoke test 后，直接
  OpenAI-compatible 调用和 Cortex HTTP/SSE turn 路径都返回 `OK`；provider
  thinking 参数修正为 `chat-template-enable-thinking`。
- SDK 发布节奏继续独立；`cortex-sdk` 保持 `1.6.4`。

`1.6.7`、`1.6.6`、`1.6.5`、`1.6.4`、`1.6.3`、`1.6.2`、`1.6.1` 与 `1.6.0`
的证据线仍属于当前发布历史：memory extraction completeness、Telegram/QQ
`/think` controls、vLLM thinking request mapping、plugin minimum-version
compatibility、default-hidden thinking controls、embedding credential propagation、
model-specific token-limit inference、protected-root governance、channel permission
correction、plugin effect accuracy、cache-friendly Executive assembly、provider
cache token accounting、journal/replay persistence hardening、task/goal runtime
state、ACP client support，以及 release-gate Docker authority 都没有被 `1.6.8`
削弱。

## 发布审计要求

`v1.6.8` 切版前必须满足：

1. 每个 **发布阻断** 行都必须实现，或用代码证据、测试证据、文档和限制说明重新分类。
2. 每个 **部分完成** 行都必须有验收测试证明 release claim，或在公开限制中避免过度宣称。
3. Release report 必须包含本表最终状态、严格 Docker Compose gate 结果，以及 behavior/safety/replay/soak 证据。
4. 任何 P2 宣称不得进入 README 或 release notes，除非对应审计行不再是部分完成或发布阻断。
